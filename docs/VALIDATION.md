## 复现方式

核心测试（不安装依赖；加密测试与压缩测试按环境显示 skip）：

```sh
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```

启用加密合成测试时，由操作者提供已审阅库的位置和摘要；环境变量只传库路径与公开摘要，不传密钥：

```sh
export KIT_TEST_SQLCIPHER='<absolute-reviewed-library>'
export KIT_TEST_SQLCIPHER_SHA256='<that-library-sha256>'
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```

如缺任一变量，4 个加密测试明确跳过；如果变量指向错误库或摘要不符，测试报错，不悄悄改用 SQLite。可选 Zstandard 测试只有现有 Python 环境具备包时才执行。运行时的 LLDB API、签名、进程、用户退出及恢复测试都是模拟对象，不调用真实工具；当前代码已移除应用退出 Apple Event。系统权限窗口组件只测试合成策略，不读取真实窗口。

发布候选扫描：

